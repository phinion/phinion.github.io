# Building My Portfolio

I've decided to rebuild my personal website!

My previous portfolio was built using HTML and CSS,
but I wanted something more flexible.

## Why Astro?

I wanted a framework that would let me:

- Write my own HTML and CSS
- Experiment with JavaScript
- Create reusable components
- Publish blogs using Markdown
- Showcase my games and creative projects

## What I've Built So Far

I've migrated my existing website to Astro.

My projects now use Content Collections, allowing
each project to have its own dedicated page.

I've also added category and project-type filters.

## What's Next?

I'm planning to experiment with interactive
backgrounds, playable game demos and other
creative ideas.

This website is going to be an ongoing project!
