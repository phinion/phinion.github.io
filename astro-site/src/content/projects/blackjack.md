# Blackjack

Simple console-based blackjack game made in C++, using Microsoft Visual Studio 2017, for my first year unit (Introduction to Programming)

Single player game where the player has to acquire playing cards whose combined face value is equal to 21, but not over 21 whilst betting against the dealer.
