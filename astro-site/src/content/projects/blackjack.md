## Overview

Blackjack was a first-year university project developed for my **Introduction to Programming** module at Bournemouth University.

Using C++ and Microsoft Visual Studio 2017, I created a single-player, console-based version of the classic card game, where the player competes against a dealer and aims to reach a hand value as close to 21 as possible without going over.

## Development

The project focused on implementing the fundamental rules and gameplay logic of Blackjack within a command-line application.

Having already gained some programming experience before university, I found the core assignment relatively straightforward. This gave me the opportunity to take the project further by implementing **input validation and error handling** to ensure that invalid or unexpected player inputs wouldn't cause the game to crash or behave incorrectly.

This reinforced the importance of writing robust, reliable code and accounting for unexpected user behaviour.

## Reflections

Although Blackjack is one of the simplest projects in my portfolio, I've chosen to include it because it represents one of my earliest milestones at university.

Looking back, it's a reminder of where my journey into professional game development began.
