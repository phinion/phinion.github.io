## Overview

As part of a university assignment, I developed a basic 3D game engine using C++ and OpenGL. The objective was to build an engine capable of rendering 3D objects and allowing the user to navigate the scene using a camera.

Unlike working in Unity, where many of these systems are already provided, this project involved implementing the underlying functionality directly in code, without a graphical editor or engine interface.

## Development

The engine was structured around an entity-component system, introducing me to an architectural approach used in modern game engines.

Development started with learning how to render a simple square using OpenGL, before progressing to a 3D cube.

I then expanded the project beyond the basic requirements by implementing:

- Texture mapping on 3D objects.
- Loading and displaying a 3D model.
- A free-moving camera for navigating and looking around the scene.
- Background music from *Avatar: The Last Airbender*, added for fun.

## What I Learned

This project gave me a better understanding of the fundamentals behind 3D game engines, particularly graphics rendering, working with OpenGL and structuring a program around entities and components.

It was an interesting opportunity to explore the systems that game engines typically handle behind the scenes.
