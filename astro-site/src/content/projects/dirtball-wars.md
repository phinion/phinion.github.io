## Overview

Dirtball Wars was a first-year university project developed for my **Object-Oriented Programming** module at Bournemouth University.

Using C++ and the SDL library, I created a simple 2D artillery-style game inspired by *Raft Wars* on Miniclip.

The game features two dirtballs battling against each other by launching projectiles, with the aim of hitting their opponent.

As the assignment focused on programming rather than artwork, I kept the visuals simple and concentrated on implementing the gameplay mechanics.

## Development

This project built upon the C++ fundamentals I had explored in my earlier Blackjack assignment, introducing me to graphical game development using SDL.

Development began with rendering simple shapes before progressing towards a playable game with basic physics and enemy behaviour.

Some of the key mechanics I implemented included:

- **Aiming & Power:** Players use an aiming reticle to determine the direction and strength of their shots. The further the reticle is positioned from the player, the more powerful the shot becomes.
- **Projectile Physics:** Implemented basic gravity calculations to create curved projectile trajectories.
- **Enemy Behaviour:** Created a computer-controlled opponent with randomised shooting behaviour to simulate an AI opponent.
- **Gameplay Timer:** Added a timer as part of the game's mechanics.

Although relatively simple, these features helped me explore how different gameplay systems could work together to create an interactive experience.

## Reflections

Dirtball Wars was an enjoyable opportunity to move beyond console applications and start creating something that looked and felt like a video game.

Looking back with the experience I have today, there are plenty of things I would approach differently or expand upon, particularly in terms of visuals, physics and gameplay design.

However, it's fun to revisit this project and see how I was beginning to combine my programming knowledge with my own ideas as a game developer.
